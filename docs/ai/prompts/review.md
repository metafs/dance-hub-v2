# Review Prompt

Review the proposed change without modifying files.

Review against:

1. Issue acceptance criteria
2. Product requirements
3. Architecture and ADRs
4. Data integrity
5. Authorization and security
6. Tests and validation evidence
7. Regression risk
8. Unrelated or unnecessary changes

Prioritize substantive problems over stylistic preferences.

Classify findings:

- P0 critical
- P1 major
- P2 moderate
- P3 minor

For every finding provide:

- file / location
- problem
- impact
- recommended fix

If no substantive findings exist, say so explicitly and list any remaining uncertainty.
