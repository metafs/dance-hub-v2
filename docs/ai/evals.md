# DANCE HUB — Agent Evaluation Log

Use this file (or a future structured replacement) to compare Codex and Claude Code on actual project tasks rather than general impressions.

## Metrics

- Agent
- Model / configuration when known
- Prompt version
- Task category
- Requirement / acceptance-criteria completion
- `pnpm check` result
- `pnpm verify` result
- Review findings by severity
- Human corrections required
- Unrelated diff / scope creep
- Architecture violations
- Cost / usage notes when available
- Final outcome

## Evaluation principle

Do not seek a single universal winner. Use accumulated project evidence to determine which agent or workflow performs best for each task category.
