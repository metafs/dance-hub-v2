# ADR-0017: 掲載審査で作品の質を判断しない

**Status:** Accepted
**Accepted:** 2026-09-19

## Context

本サービスは ADR-0006 の Organization 事前承認と、ADR-0007 の Event Revision 審査を伴う。審査が存在する以上、「何を審査するのか」を定義しなければ、判断は運営者個人の裁量に落ちる。

この判断が裁量である場合、以下が起きる。

- 運営者は当事者（作家）であり、審査は同じシーンの他者に対する評価として受け取られる。「なぜあの団体は掲載され、うちは掲載されないのか」は必ず発生する。
- 不承認の理由が説明できない。「総合的に判断した」は、恣意的な排除と区別がつかない。
- 立ち上げ期に掲載在庫が必要な段階で、審査が在庫の制約になる。

同時に、審査を完全に廃止すると別の問題が生じる。詐欺的なオーディション、勧誘目的のイベント、虚偽情報が混入し、サービスの信頼が失われる。主催者への訴求（掲載されている場所の形式が保たれている）も成立しなくなる。

## Decision

掲載審査は形式要件と権利要件のみを判断し、作品の質・芸術性・ジャンルの正統性・団体の規模や知名度を判断しない。

- 判断基準は `docs/product/listing-policy.md` として公開する。
- 不承認の通知には該当条文番号を記載する。
- 編集的な判断（紹介・キュレーション）は掲載審査から分離し、別の行為として扱う。紹介の基準は公開せず、説明義務を負わない。
- 運営関係者が関与する Event も同一フローを通る。

判断が条文として書けないものは、基準にしない。書きたくなった時点で、それは掲載審査ではなく紹介側で扱うべき問題である。

## Alternatives considered

### キュレーション型（運営が掲載可否を編集判断する）

掲載されている Event の水準を運営が制御でき、サービスのトーンを保ちやすい。既存の批評メディアに近い立ち位置を取れる。

採用しない。判断基準が説明できず、運営者が当事者であることと両立しない。また、掲載在庫を運営者の可処分時間が律速するため、発見のためのプラットフォームとして成立しない。

### 招待制（承認済み Organization のみが掲載できる）

質の担保と運用負荷の軽減を同時に達成できる。

採用しない。新規の個人・団体が参入できず、最初の一本を掲載できない。既存の情報チャネル（劇場サイト、チケット販売サイト）に対する優位が消える。

### ハイブリッド（形式審査 + 質による表示順の制御）

掲載は機械的に行い、表示順やレコメンドで質を反映する。

採用しない。判断が不可視になるだけで、裁量の問題は解決しない。むしろ説明責任が果たせなくなる。ただし、人力キュレーション（紹介）として明示的に分離された形であれば問題はなく、本 ADR はその形を採用している。

## Consequences

- 掲載審査の所要時間が短くなり、審査上限（週 20 件）の範囲で運用できる。
- 掲載 Event の質は一定しない。発表会、コンテスト、実験的な小規模公演が同じ一覧に並ぶ。これは ADR-0008 の Event Type による分類と、紹介（キュレーション）によって扱う。
- 「載っているものの水準が高い」という訴求は使えない。主催者への訴求は「掲載が無料で、検索から発見され、形式が整っている」に置き換わる。
- 掲載基準を公開するため、基準の変更は公開された変更として行う必要がある。
- `docs/product/listing-policy.md` が掲載可否の正本となる。`docs/product/requirements.md` と `docs/product/scope.md` は、掲載可否に関する記述をこの文書に委ねる。

## Revisit when

- 条文に当てはまらない例外判断の記録が三件を超えたとき（`docs/product/listing-policy.md` G-4）。
- 掲載在庫が十分に積み上がり、審査が在庫の制約でなくなったとき。
- 出演条件（チケットノルマ、出演料の有無）を開示項目として扱う設計を検討するとき。本 ADR は除外基準としないことのみを決定しており、開示による透明化は否定していない。
