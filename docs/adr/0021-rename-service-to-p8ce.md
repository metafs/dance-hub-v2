# ADR-0021: サービス名を p8ce とする

**Status:** Accepted
**Accepted:** 2026-09-21
**Supersedes:** ADR-0019

## Context

ADR-0019 はサービス名を `p9e`（読み: ピーナイン）と定めた。改名の実施前に、performance から作れる numeronym を全列挙（2046 通り）して意味の層を検討し直した結果、`p8ce` を採る。

ADR-0019 の判断材料には誤りが一つあった。検討の過程で「`p9e` の綴りから読み『ピーク』は導けない」としたが、`p` をピー、`9` を「く」と読む語呂は標準的であり、`p9e` → ピークは綴りから自然に導ける。本 ADR はこの誤りを正したうえで判断している。

ADR-0019 が改名を必要とした理由（既存サービスとの衝突、listing-policy A-2 との矛盾、機能語であること）はそのまま有効であり、本 ADR は名称の選択のみを置き換える。

## Decision

サービス名を `p8ce` とする。

- **表記:** `p8ce`。小文字を正とする。
- **読み:** ペイス。
- **由来:** performance の numeronym。先頭 `p`、中間8文字（erforman）、末尾 `ce`。
- **一行説明:** 関東・関西のダンスとパフォーマンスを探す。
- **タグライン:** どの上演にも、それぞれのペースがある。
- **repository:** `metafs/p8ce`。
- **ドメイン:** 保留（第一候補 `p8ce.dance`）。

名称・読み・一行説明・タグライン・ロゴの使い方の規則は `docs/brand/identity.md` に置く。本 ADR は理由を置く。

### 綴りの層

`p8ce` は一つの綴りに四つの層を持つ。

- **performance の numeronym。** `k8s`、`i18n` と同じ機構。
- **pace。** 英語のテキスト表記で `8` が /eɪt/ の音を担う規則（`gr8` = great、`sk8` = skate、`l8r` = later）により、`p` + eight + `ce` がそのまま pace と読める。この規則は英語話者に通じるため、post-MVP の英語化で読みの問題が再燃しない。
- **エイトカウント。** ダンスの時間の単位。
- **P8。** 音程の完全8度、オクターブ。

表に出すのは pace のみとする。8 で数えるのはストリート、ジャズ、バレエの文化であり、舞踏、パフォーマンスアート、演劇は 8 で数えない。listing-policy A-2 でジャンルによる除外を行わない以上、エイトカウントは知る者だけが気づく層にとどめる。

### タグラインについて

pace は優劣ではなく固有性を指す。「どの上演にも、それぞれの」は、上演どうしを序列化しないという ADR-0017 の立場を名称の水準で言うものであり、省略できない。「最良のペース」のような、比較や選別を含意する言い換えを公開文面で用いない。

ADR-0018 で記録の永続性を手放した以上、本サービスの重心は「これから起きる上演」にある。pace はその時間的な性格と一致する。

### 読みについて

ペイスとする。pace の実際の発音に近い。ペースは「マイペース」の普通名詞であり、「ペース ダンス」のように修飾語を足しても検索で埋もれる。ペイスは表記として使われる頻度が低く、わずかに識別しやすい。口頭で名を聞いた者が検索で到達できることを読みの要件とする。

## Alternatives considered

### p9e（ADR-0019）

3文字で短く、読みを二つ持ちうる（ピーナイン／ピーク）。

採用しない。ピーナインは P9 という型番の製品（スマートフォン、タイヤ、自転車、加熱式たばこ等）の読みとして広く流通しており、単独では識別力を持たず、意味も持たない。ピークは綴りから導けるが、「混雑のピーク」の普通名詞であり検索で埋もれるうえ、頂点・最良という含意が ADR-0017 と衝突しやすい。event / entertainment 領域にも同音の事業者が複数ある（ピーク・ワン、ピークエンタテインメント）。`p8ce` は語として読め、英語話者にも通じ、含意が ADR-0017 と整合する。

### 読み：ペース

日本語として最も自然に発話できる。

採用しない。普通名詞であり、口頭から検索への導線が切れる。

### 読み：ピーキー（p9e に対して検討）

記憶に残りやすい。

採用しない。「扱いづらい・尖った」の含意が、名称の態度として対象を狭く見せる。listing-policy A-2 との矛盾は、DANCE HUB を捨てた理由と同じ構造である。

### p5m3e

音程記法で完全5度（P5）と短3度（m3）を持ち、末尾の e を根音とすると E マイナーの三和音を綴る。字面の多義性は最も深い。

採用しない。口頭で発話できない。about などで裏の層として言及する余地は残す。

### 9ce / 1e9 / 10e 等（CSS の16進色になる形）

照明の RGB と CSS の色表記が同じ一語になる。`9ce` は語呂で「癖」とも読める。

採用しない。サービス名としては語として読めない。UI のアクセント色の候補として `docs/brand/identity.md` に記録する。

### per8

per eight（8カウントごとに）。発話でき、検索でも埋もれにくい。

サービス名としては採用しない。8カウントを表の層に出すことになり、上記の理由でジャンルを狭める。週次キュレーションの名称の候補として残す。

## Consequences

- **ADR-0019 は Superseded とする。** 名称の選択以外の部分（改名の理由、M5 以前に実施する必要）は本 ADR が引き継ぐ。
- **検索の衝突は小さい。** 本 ADR 作成時点で、`p8ce` は IBM FileNet の内部略号とペイントボール掲示板の投稿に使われているのみで、舞台芸術・イベント領域に使用例はない。
- **読みの併記は引き続き必要。** `README.md`、公開ページ、SNS プロフィール、印刷物に「ペイス」を併記する。
- **数字の字形を固定する。** ロゴの `8` はライニング数字とする。小文字列の中で 8 がキャップハイトまで立ち上がるのは意図した字形であり、オールドスタイル数字やエックスハイトへの縮小に差し替えない。
- **改名の範囲と手順は `docs/plans/rename-plan.md` に従う。** ドメインは保留とし、改名の前提条件としない。公開前に決める。
- **ロゴの正本は `docs/brand/logo/` に置く。** 使い方の規則は `docs/brand/identity.md`。

## Revisit when

- ドメインを決めるとき。候補がいずれも取得できない場合は名称ごと再検討する。改名の実施後にこれが起きた場合、置換をやり直すことになる。
- 商標登録を検討するとき。
- ペイスという読みが定着せず、現場で別の読み（ペース、ピーエイトシーイー等）が自然発生したとき。その場合は自然発生した読みを正とする。
- タグラインが上演の比較や選別を意味すると受け取られる事例が生じたとき。
