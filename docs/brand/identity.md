## Purpose

この文書は、サービス名・読み・一行説明・タグライン・ロゴの使い方の正本である。決定の理由は ADR-0021 に置く。

## 名称

| 要素 | 値 |
| --- | --- |
| 表記 | `p8ce`（小文字を正とする） |
| 読み | ペイス |
| 一行説明 | 関東・関西のダンスとパフォーマンスを探す |
| タグライン | どの上演にも、それぞれのペースがある。 |

### 表記の規則

- 大文字の `P8CE` はロゴ・見出し・文中のいずれでも用いない。識別子として大文字が必要な箇所のみ `P8ce`、環境変数・定数は `P8CE`。
- 読みは綴りから推測しにくいため、初出では必ず併記する。印刷物・SNS プロフィール・口頭の紹介を含む（「ペイス、`p8ce` と書きます」）。
- `8` を「エイト」と読ませる表記（ピーエイトシーイー等）を公式には用いない。

### 一行説明とタグライン

名称に機能を説明させないため、名称の直下に二つの要素を置く。役割が異なるので混ぜない。

- **一行説明が主。** 初見の読み手に「これは何か」を伝える。`p8ce` が単独で置かれる箇所には、原則として一行説明を伴わせる。
- **タグラインは従。** about、公開ページの冒頭、印刷物など、読み手が既に文脈を持つ場所で用いる。一行説明の代わりに置かない。

```
p8ce ／ ペイス
関東・関西のダンスとパフォーマンスを探す
```

「どの上演にも、それぞれの」は省略できない。ADR-0017 が上演の質を判断しないと定めている以上、比較や選別を含意する言い換え（「最高のペース」「ペースを選ぶ」等）を公開文面で用いない。

## ロゴ

### 構成

ロゴは、曲線とロゴタイプの二つで構成する。

- **ロゴタイプ:** `p8ce`。Instrument Sans SemiBold（600）。字間は詰め（-0.04em 相当）。
- **8 の字形:** ライニング数字。小文字列の中で 8 がキャップハイトまで立ち上がるのは意図した字形であり、オールドスタイル数字やエックスハイトへの縮小に差し替えない。
- **曲線:** ロゴタイプの上に置く一本の細線。左は平らに始まり、ゆるやかに膨らんで肩のように丸い頂点に達し、長く尾を引いて右で平らに戻る。立ち上がりは減衰より短い。
- **頂点の点:** 曲線の頂点に置き、8 の上に置く。位置の正は正本 SVG であり、字形の寸法から再計算して動かさない。

曲線は上演の山場ではなく、テンポの変化（pace）を描く。形を調整する場合も、尖った頂点や左右対称の山にしない。

### 正本の素材

正本は Figma で調整した最終版から書き出した SVG であり、`docs/brand/logo/` に置く。ロゴを使う箇所はこれらを参照し、再描画・再構成しない。

| ファイル | 用途 |
| --- | --- |
| `docs/brand/logo/p8ce-logo.svg` | 正（`#141414`、地 `#ffffff`） |
| `docs/brand/logo/p8ce-logo-inverse.svg` | 反転（`#ffffff`、地 `#141414`） |
| `docs/brand/logo/candidates/` | 検討中の色。正式な用途に用いない |

いずれも 456×456 の正方形で、地の矩形を含む。透過版と、余白を詰めた横長の版は未作成（Open items）。

正方形の版を SNS のアイコンにそのまま使わない。円形に切り抜かれると `p` のディセンダーの角が欠け、アイコンの表示サイズでは曲線が消える。SNS アイコンは下記「サイズ」の規則に従い、ロゴタイプのみで別に組む。

### サイズ

| ロゴタイプの文字サイズ | 表示 |
| --- | --- |
| 40px 以上 | 曲線とロゴタイプ |
| 40px 未満 | ロゴタイプのみ |

曲線は縮小すると線が消えるため、小サイズでは落とす。ファビコン・アプリアイコン・SNS アイコンはロゴタイプのみとする。

### 色

**正式な組み合わせは次の二つのみ。**

| 組み合わせ | 線・文字 | 地 |
| --- | --- | --- |
| 正 | `#141414` | `#ffffff` |
| 反転 | `#ffffff` | `#141414` |

曲線・点・ロゴタイプは常に同じ色とする。曲線だけを別の色にしない。

**検討中の色**（未決。正式な用途に用いない）

| 色 | 白地でのコントラスト | 黒地でのコントラスト |
| --- | --- | --- |
| `#c29940` 金 | 2.65 | 6.95 |
| `#1a8059` 緑 | 4.91 | 3.75 |
| `#1a2659` 紺 | 14.33 | 1.29 |
| `#cc2626` 赤 | 5.42 | 3.40 |
| `#99ccee` 淡青（`9ce`） | 1.72 | 10.73 |

白地で本文の文字色として 4.5:1 を満たすのは緑・紺・赤。黒地で 4.5:1 を満たすのは金と `#99ccee` で、緑と赤は 24px 以上の大きな文字に限り 3:1 を満たす。金は候補のうち唯一、黒地を前提に書き出されている。`#99ccee` は performance の numeronym `9ce` でもある。UI は無彩色を基本とする方針のため、採る場合もアクセントとして一色に絞ることを想定する。
