# DANCE HUB — Claude Code Instructions

Read `AGENTS.md` first. It contains the shared repository rules and source-of-truth map.

For non-trivial implementation work use this sequence:

1. Inspect
2. Plan
3. Implement
4. Verify
5. Review

Additional rules:

- Do not infer missing product requirements.
- Prefer focused changes over broad refactors.
- Use repository-provided validation commands rather than inventing an ad-hoc validation flow.
- Before finishing, inspect the diff, update relevant documentation, and report remaining risks or uncertainty.
